# GEOFlow 内容生产改造方案

## 1. 当前目标

GEOFlow先独立改造成稳定的内容生产与分发系统，不依赖seo-diagnostic：

1. 每天生成一篇高质量简体中文主文章。
2. 结合企业知识库、URL资料和可选搜索研究，保证内容有依据。
3. 文章通过质量检查和审核后发布到WordPress。
4. 从已审核主文章生成百家号、腾讯、网易、搜狐、头条、知乎和微信公众号版本。
5. 全流程支持追踪、暂停、重试、审核和失败恢复。

本阶段不建设外部系统对接，不共享数据库，不设计seo-diagnostic回调。

## 2. 设计原则

- 不推倒现有知识库、任务、文章、内容组和分发底座。
- 不再用一次大提示词完成研究、写作和审核。
- 引导式、自动式、批量式创作共用一条生产流水线。
- SERP只是研究来源，模板AI只是编辑器辅助能力。
- 默认生成简体中文，质量不达标不自动发布。
- 文章事实、证据、规则版本、模型和修改过程可追溯。
- 保持上游代码可合并，优先新增独立服务和数据结构。

## 3. 统一文章生产流水线

| 阶段 | 输入 | 输出 | 默认人工确认 |
|---|---|---|---|
| 创建项目 | 网站、栏目、主题、受众、语言、目标 | 创作项目 | 否 |
| 重复检查 | 主题、网站历史文章 | 重复风险、差异化建议 | 高风险时 |
| 资料研究 | 知识库、URL、可选SERP | 研究报告、证据卡片 | 深度模式 |
| 内容简报 | 研究结果、品牌规则、文章类型 | 核心观点、问题、证据、CTA | 标准/深度模式 |
| 标题方案 | 简报、关键词、历史标题 | 多个标题及选择理由 | 引导式模式 |
| 大纲方案 | 简报、标题、篇幅 | H2/H3、章节目的、证据映射 | 引导式模式 |
| 分段写作 | 大纲、章节证据 | 章节草稿 | 否 |
| 合稿编辑 | 章节草稿、风格规则 | 完整主文章 | 否 |
| 质量检查 | 文章、证据、规则 | 报告、问题清单 | 否 |
| 定向修复 | 未通过项 | 修复稿、差异 | 超过重试上限时 |
| 人工审核 | 文章、质量报告 | 通过、退回、修改 | 是 |
| WordPress发布 | 审核稿、渠道配置 | 远端ID和URL | 按规则 |
| 平台改写 | 已审核主文章、平台规则 | 七个平台版本 | 是 |

每个阶段保存状态、输入摘要、输出、模型、规则版本、耗时、失败原因和重试次数。失败后从当前阶段继续，避免整篇重跑。

## 4. 创作模式

- **引导式创作**：人工选择标题和大纲，适合重点文章。
- **标准自动创作**：自动完成研究到质量检查，进入人工审核。
- **快速创作**：减少研究步骤，适合低风险短内容。
- **批量生产**：多个选题分别调用标准流水线。
- **编辑器辅助**：人工写作为主，AI负责局部扩写、改写和检查。

所有模式使用同一个核心生成服务。

## 5. 核心功能

### 5.1 写作规则

写作规则需要版本化，配置：

- 适用网站、语言、地区、目标读者和内容目标。
- 品牌语气、专业程度、文章类型、篇幅和结构。
- 知识库、URL和SERP研究策略。
- 标题、大纲、正文、引用和元数据要求。
- 图片、FAQ、CTA、内链和外链策略。
- 禁止表达、风险规则、事实要求和质量阈值。
- 主模型、备用模型、审核、修复和发布策略。

普通用户使用表单，高级配置可导入导出JSON，但不要求手写JSON。

### 5.2 文章类型库

首期保留：

- 知识科普
- 操作指南
- 产品或解决方案
- 比较文章
- 列表或推荐
- 案例文章
- 新闻资讯
- 常规博客

每个类型定义适用意图、必填资料、推荐结构、默认篇幅、事实检查、引用、FAQ和CTA。

### 5.3 内容资产中心

- **知识库**：产品、行业、案例、技术和服务资料。
- **URL资料**：采集、清洗、预览、复核和入库。
- **品牌库**：定位、客户、标准介绍、核心优势和CTA。
- **竞品库**：竞品事实、比较维度和来源。
- **素材库**：Logo、产品图、截图、封面和正文图片。
- **表达规范**：术语、敏感词、禁止承诺、AI套话和品牌语气。

知识片段保存来源、更新时间和可信等级；文章保存实际使用的证据片段。

### 5.4 选题与关键词

在现有标题库和关键词库基础上统一管理：

- 主题、主关键词、相关问题和主题集群。
- 搜索意图、目标读者、文章类型和优先级。
- 来源：人工、文件、网站分析、SERP或AI扩展。
- 状态：候选、已排期、生成中、已发布、需更新、停用。
- 对应文章、网站、栏目和内容组。
- 重复风险、最后使用时间和失败原因。

### 5.5 文章编辑器

局部能力：

- 扩写、精简、改写和语气调整。
- 转简体中文、删除AI套话、补充证据、添加引用。
- 转换为列表、表格或指定平台格式。

整篇能力：

- 标题、摘要、Meta Description、FAQ和CTA生成。
- 事实、语言、重复、风险、SEO/GEO和品牌一致性检查。
- 变更差异预览、接受、拒绝和版本恢复。

AI修改不能直接覆盖原文。

### 5.6 质量门禁

发布前检查：

- 简体中文比例和非必要外语。
- 事实是否有知识或来源支持。
- 引用URL是否存在且与事实匹配。
- 标题、正文与用户意图是否一致。
- 与本站已有文章的重复和内容蚕食。
- 品牌名称、产品事实、语气和CTA是否一致。
- 敏感词、夸大承诺和风险表达。
- 结构、FAQ、内链和SEO元数据是否完整。
- 关键词是否自然覆盖，不使用机械密度要求。

只修复未通过的章节；达到重试上限后转人工处理。

### 5.7 每日生产任务

任务配置：

- 选题来源和筛选条件。
- 写作规则及版本。
- 每日数量、时间和时区。
- 目标WordPress网站、栏目和标签。
- 草稿、审核或自动发布策略。
- 失败重试、暂停条件和成本上限。
- 是否生成平台版本及平台范围。

每个选题只能被一个任务实例消费，任务、文章和发布都使用幂等键。

### 5.8 内容组和平台版本

```text
主文章
├── WordPress快照
├── 百家号版本
├── 腾讯版本
├── 网易版本
├── 搜狐版本
├── 头条版本
├── 知乎版本
└── 微信公众号版本
```

平台稿继承主文章事实和证据，独立调整标题、开头、篇幅、结构、排版、标签和CTA。主文章更新后提示平台稿过期，不覆盖人工编辑版本。

### 5.9 发布

- WordPress复用现有REST渠道、媒体上传、分类标签、日志、重试和远端元数据。
- 其他平台首期提供预览、复制、封面下载、发布包和URL回填。
- 后续仅为具备稳定官方接口或可靠授权的平台增加自动发布。
- 不把Cookie作为长期凭据方案。

## 7. 实施阶段

### 阶段A：高质量单篇生产

- 创作项目与阶段记录。
- 研究报告、证据卡片和内容简报。
- 标题候选、大纲候选和分章节生成。
- 中文、事实、重复、风险和SEO/GEO检查。
- 编辑器差异审阅和人工审核。

验收：一篇文章的来源和生成过程可追踪，失败可断点重试。

### 阶段B：写作规则与文章类型

- 写作规则、文章类型和版本管理。
- 内容资产与品牌表达规范。
- 规则测试和结果对比。

验收：规则可复用、可回滚，历史任务继续关联原版本。

### 阶段C：每日自动生产

- 选题状态和消费控制。
- 每日计划、预算、暂停和失败恢复。
- WordPress草稿与自动发布策略。

验收：每天按规则生成中文文章，质量不达标不发布，重试不重复发文。

### 阶段D：平台版本

- 批量生成七个平台版本。
- 平台审核、版本历史、导出和发布回填。
- 主文章更新后的过期提示。

验收：各平台版本事实一致、互不覆盖、失败隔离。

### 阶段E：SERP与编辑器增强

- SERP研究报告和来源管理。
- 内容缺口、用户问题和竞品覆盖分析。
- 编辑器高级AI辅助。

验收：搜索资料只作为研究证据，不直接拼接或仿写。

## 8. 当前不做

- 与seo-diagnostic或其他工作台对接。
- GEO品牌监测和自然搜索诊断。
- 非官方登录自动化和Cookie发布。
- 删除上游模块或历史数据表。
- 大规模重做前台主题系统。

## 9. 总体验收

- 不进入高级功能即可完成每日生产。
- 每篇文章默认使用简体中文。
- 事实、引用、规则、模型和阶段记录可追溯。
- 质量门禁失败不会自动发布。
- WordPress发布幂等、可重试、可追踪。
- 一个主文章可生成七个平台版本且不改变核心事实。
- 任一平台失败不影响其他版本。
- 上游更新仍可合并到定制分支。
