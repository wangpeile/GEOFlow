# 内容生产生产验收清单

## 上线前

- 先执行数据库迁移，再启动队列消费者和定时调度。
- 确认内容生产开关、管理员权限、写作规则版本、知识库和 WordPress 站点已配置。

## 内容专题与生产计划

1. 新建专题并建立至少两个候选选题。
2. 配置生产计划，绑定专题，选择固定规则版本、时区、执行时间和每日数量。
3. 立即执行一次，确认只创建一张文章工作单，并能查看专题与规则快照。
4. 确认选题变为“生成中”；失败时变为“待更新”，且可从计划页重试。
5. 修改专题规则，确认已有工作单快照不变。

## 发布包中心

1. 为审核后的主文章建立发布包，确认 WordPress 和平台版本在同一个发布包。
2. 生成、人工编辑、审核通过并导出一篇平台稿，确认版本历史完整保留。
3. 修改主文章，确认发布包提示平台稿需要复核。
4. 确认提醒不会自动覆盖人工修改的平台稿。
5. WordPress 默认保存草稿；正式发布必须在发布包中单独提交。

## 兼容与回归

- 访问旧“内容项目”和“每日内容生产”链接，确认正确跳转。
- 确认历史文章、自动任务、发布记录和平台稿仍可访问。
- 在发布包中心验证搜索、状态总览和失败信息。
